# Design: Rename "今日未列印印表機" to "未收到資料列表"

## Context

`no_print_today.html` 是一個單頁 HTML 應用程式，用於顯示今日印量為 0 的印表機列表。當前命名（「未列印」、「統計時間」）與實際功能（顯示未收到資料或資料為 0 的印表機）存在語意落差。

此變更不影響任何業務邏輯或篩選條件，僅是命名與顯示文字的調整。

## Goals / Non-Goals

**Goals:**
- 將頁面所有「未列印」相關命名改為「未收到資料」
- 將「最近統計時間」改為「上次抓取時間」，反映實際資料來源
- 保持所有現有功能與行為不變

**Non-Goals:**
- 不修改篩選邏輯或業務規則
- 不新增或移除任何功能
- 不變更任何 API 或資料庫結構

## Decisions

1. **僅修改字串常數**：所有更動僅限 HTML 文字、CSS class 無關的內嵌文字、JS 變數名稱與註解。不觸及任何樣式或佈局。
2. **變數名稱同步更新**：`last_recorded` → `last_fetched`、`recordedAt` → `fetchedAt`，保持命名一致性。
3. **保留「無」的顯示**：當無資料時仍顯示「無」，不做行為變更。

## Risks / Trade-offs

| Risk | Mitigation |
|------|------------|
| 瀏覽器快取舊版 HTML | 無影響，純文字替換 |
| 其他頁面 reference 此頁的 URL | 不改檔名，僅改頁面內容 |
| 使用者習慣舊名稱 | 僅內部使用，不影響外部使用者 |

## Migration Plan

單一 HTML 檔案修改，無需資料庫或後端變更。直接部署即可。
